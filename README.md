## 🌟 Özellikler

* **⚡ Işık Hızında Arayüz:** Akıcı bir çapraz platform deneyimi için Flutter ile geliştirildi.
* **🛡️ Güçlü Arka Plan (Backend):** Yüksek ölçeklenebilirlik ve güvenli uç noktalar sunan .NET 8 Web API altyapısı.
* **🐘 Güvenilir Veritabanı:** Güvenilir ve hızlı veri saklama için PostgreSQL desteği.
* **🔒 Kurumsal Düzeyde Güvenlik:** Hassas veritabanı kimlik bilgilerini koruyan çevre izoleli yapılandırmalar.
